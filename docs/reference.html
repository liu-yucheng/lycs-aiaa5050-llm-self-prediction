Reference

The five tools, the command line, the two settings, and every file that a session writes.

1. Tools

ToolArgumentsOutput
llm_self_prediction_run providers, tasks, limit, repetitions, toleranceNats, outputDirectory, seed, maxConcurrency, topLogprobs, dryRun The session code, the directory, the report path, the task count, the pair count, the verdict of each provider, and the warnings.
llm_self_prediction_status limit The recent sessions, newest first, with the status, the task count, the failure count, and the verdicts.
llm_self_prediction_report session The session code, the report path, and the Markdown text.
llm_self_prediction_dataset sample The dataset identifier, the language, the task count, the category counts, and the first tasks.
llm_self_prediction_help none The experiment summary, the provider table, and the run steps.

2. Run arguments

ArgumentTypeDefaultMeaning
providers string array every enabled provider The provider keys of the run.
tasks string array every task The task identifiers of the run, in dataset order.
limit integer 0 The maximum task count. A value of 0 selects every task.
repetitions integer 4 The count of answers of each mode for one task.
toleranceNats number 0.05 The separation tolerance in nats.
outputDirectory string the configured root The output root of the session directory.
seed integer 20260815 The seed of the bootstrap and of the session code.
maxConcurrency integer 3 The maximum count of concurrent task jobs, from 1 to 16.
topLogprobs integer the provider value The support size of both modes, from 1 to 64. The value overrides every provider section.
dryRun boolean false Use the mock provider and no network access.

An unknown argument is ignored. An argument of the wrong type stops the run with the message The argument NAME is not ....

3. Command line

node lib/cli.js run --dry-run --limit=3 --repetitions=2
node lib/cli.js run --providers=deepseek,qwen --limit=8 --tolerance=0.02
node lib/cli.js status --limit=5
node lib/cli.js report --session=20261122T133644Z-20260815-60375c
node lib/cli.js dataset --sample=8
node lib/cli.js env
CommandOptions
run --providers, --tasks, --limit, --repetitions, --tolerance, --output, --seed, --concurrency, --top-logprobs, --dry-run
status--limit, --output
report--session, --output
dataset--sample
env none. The command copies the example file when the private file is absent.
helpnone

An option accepts both forms --name=value and --name value. The exit code is 0 for a success, 1 for a handled error, and 2 for a usage error.

4. Settings

The bundle patch mounts one row with the id aiaa5050-llm-self-prediction.

SettingDefaultMeaning
outputRoot empty The output root. An empty value uses outputs in the workspace. A relative value resolves against the workspace.
maxConcurrency 3 The maximum count of concurrent task jobs, clamped to 1 through 16.

A setting of the wrong type falls back to its default, so a bad row never stops the plugin from loading.

5. Output layout

Every path below sits in outputs/<session code>/ of the workspace, unless the outputRoot setting or the --output option names another root.

PathContent
session.json The session code, the options, the providers, the environment, and the status.
tasks.jsonThe tasks of the session.
raw/<provider>-<task>-<mode>-r<n>.json One provider reply, unedited.
raw/<provider>-<task>-<mode>-r<n>.error.json The record of one failed call.
records/<provider>-<task>.json The parsed answers, the pairs, the baselines, the warnings, and the errors.
metrics.jsonThe aggregate metrics and the verdict of each provider.
report.mdThe readable report.
summary.csvOne row for each provider.
tasks.csvOne row for each task and provider.

The session code has the form <UTC time>-<seed>-<six hex characters>, for example 20261122T133644Z-20260815-60375c.

6. Failure behavior

SituationResult
A provider has no usable key The run stops before the first call with MISSING_CREDENTIAL, and the prompt names the environment keys to fill in.
A call fails, times out, or returns an invalid reply One error file, one warning, and one missing answer. The run continues.
Every call of a task fails The record holds the errors, and the task contributes no pair.
The user cancels the run The manifest records the status failed and the reason.
The dataset file is malformed The run stops with INVALID_DATASET and the offending task.
