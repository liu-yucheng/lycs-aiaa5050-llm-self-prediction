Reference

The tool arguments, the command line, the settings, the environment keys, and the output layout.

The tool arguments

ArgumentTypeMeaning
providersstring arrayProvider keys or model keys. Empty selects every enabled model.
tasksstring arrayTask identifiers in the selected order. Empty selects every task.
repetitionsinteger 1 to 10The repetition count of each condition. Default 3.
toleranceNatsnumberThe verdict tolerance in nats. Default 0.05.
outputDirectorystringThe output root. Empty uses the plugin setting.
seedintegerThe bootstrap seed. Default 20260815.
maxConcurrencyinteger 1 to 16The number of tasks that run at the same time.
topLogprobsCountinteger 2 to 64The requested table size. Default 20.
dryRunbooleanUse the mock provider and no network.

The command line

node lib/cli.js run [options]
node lib/cli.js status [--limit=5]
node lib/cli.js report [--session=<xid>]
node lib/cli.js dataset [--sample=8]
node lib/cli.js env
node lib/cli.js help

# run options
--providers=<keys> --tasks=<ids> --repetitions=<n> --tolerance=<nats>
--output=<directory> --seed=<n> --concurrency=<n> --entries=<n> --dry-run

The plugin settings

SettingTypeMeaning
outputRootstringThe output root. Empty uses outputs/ in the workspace.
maxConcurrencyinteger 1 to 16The default worker count of one run.

The environment keys

The private file .env holds only repo_url, base_url, and api_key. The public file .env.example lists the same keys. The public file configs.env holds every other setting, such as the model list and the switches. A placeholder in angle brackets counts as an absent key. The reader reports a key outside the private set in .env and applies only the configs.env value.

The output layout

outputs/<xid>/
  run.json                     the manifest: status, options, providers, versions
  tasks.json                   the selected tasks
  intermediate/<providerKey>/<taskId>/<condition>-r<n>-call<k>.json
  results/metrics.json         the three comparisons, the summaries, the verdicts
  results/records.json         one task record for each task and model
  results/records/<providerKey>/<taskId>.json
  results/report.md            the Markdown report
  results/summary.csv          one row for each provider and comparison
  results/tasks.csv            one row for each task and comparison
  results/environment.json     the recorded versions and the elapsed time
  results/task-summary.json    the compact table that the explorer reads
  demos/index.html             the demonstration website
  demos/assets/                the style sheet, the script, and the data files

The failure modes

CodeCause
INVALID_ARGUMENTAn argument is absent, malformed, or names an unknown task.
INVALID_DATASETA dataset file breaks a validation rule.
INVALID_PROVIDERThe catalog holds no such provider, or no model reports a table.
MISSING_CREDENTIALNo API key is available for a selected provider.
PROVIDER_FAILUREThe endpoint returned an error status or no JSON body.
INVALID_RESPONSEThe reply holds no usable table.
MISSING_SESSIONThe requested run or report is absent.
