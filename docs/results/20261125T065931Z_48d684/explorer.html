How to read a pane如何读一栏

  • Probability: the normalized probability of the token in that distribution.概率：该词块在该分布中归一化后的概率。
  • Share: the part of the symmetric divergence that this token contributes.贡献：该词块对对称散度的贡献份额。
  • Missing: the token does not appear in that distribution, so it takes the floor.缺失：该词块不在该分布中，因此取概率下限。
  • Badge: green is below 0.05 nats, amber is below 0.5 nats, red is at or above 0.5.徽标：绿色低于 0.05 奈特，琥珀色低于 0.5 奈特，红色为 0.5 奈特或更高。
