The platform平台

The platform is a plugin of DeepSeek Harness, a terminal and web harness that hosts tools and agent presets. The plugin registers five tools and one command line. A run is one tool call or one command, and the run writes a directory that holds every input and every output.平台是 DeepSeek Harness 的插件。DeepSeek Harness 是承载工具和智能体预设的终端与网页运行环境。插件注册五个工具和一套命令行。一次运行是一次工具调用或一条命令，运行写出的目录保存每个输入和每个输出。

  • llm_self_prediction_run: run the four conditions on a set of tasks.llm_self_prediction_run：对一组任务运行四个条件。
  • llm_self_prediction_status: list the recent runs of the output root.llm_self_prediction_status：列出输出根目录下最近的运行。
  • llm_self_prediction_report: read the Markdown report of one run.llm_self_prediction_report：读取一次运行的 Markdown 报告。
  • llm_self_prediction_dataset: describe the packaged datasets.llm_self_prediction_dataset：说明随包的数据集。
  • llm_self_prediction_help: print the protocol and the file layout.llm_self_prediction_help：打印协议与文件布局。

Preset creation预设的创建

The experiment compares many models with one protocol, so the work splits into three agent roles. A planner reads the design and writes the task list. An operator runs the conditions and keeps each raw reply. A reviewer checks the report against the records and states the defects.本实验用同一协议比较多个模型，因此工作分为三种智能体角色。规划者读设计并写出任务清单。操作者运行各条件并保存每次原始回复。审阅者把报告与记录对照，指出缺陷。

Each role gets its own preset with three parts: a system prompt that states the role, a tool allow list that limits what the role can do, and an output contract that names the files the role must write. The preset is data, so the run records the preset version next to the result.每个角色有自己的预设，预设分三部分：说明角色的系统提示词、限制角色权限的工具白名单、规定角色必须写哪些文件的输出契约。预设是数据，因此运行会把预设版本与结果一起记录。

Providers模型提供方

The run reaches each model through an OpenAI-compatible chat endpoint. The plain actual condition sets logprobs and top_logprobs. The self conditions send no log-probability parameter at all, so the model must write the table as text.运行通过兼容 OpenAI 的对话接口访问每个模型。普通实际条件设置 logprobs 与 top_logprobs。自我条件完全不发送对数概率参数，因此模型必须用文字写出表格。
