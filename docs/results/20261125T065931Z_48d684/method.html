Prompts提示词

The plain actual condition sends the task with the log-probability request. The interface returns the top entries of the served distribution. The plain self condition sends the same task and asks for a JSON object with the entries of the model own distribution.普通实际条件发送任务，并请求对数概率。接口返回实际分布的前若干条目。普通自我条件发送同样的任务，要求模型用 JSON 对象写出自己分布的各条目。

The self condition asks for one token of one or more characters. A tokenizer can cut a word into pieces, and the model does not see the tokenizer. The prompt therefore permits the model to list the leading pieces and to give the rest of the probability to the whole word.自我条件要求一个词块，可以是一个或多个字符。分词器会把一个词切成片段，而模型看不到分词器。因此提示词允许模型列出前导片段，并把其余概率给整个词。

The run parses the reply as text. It accepts a code fence, an object, or an array. It keeps the raw reply unchanged in the intermediate directory and stores the parsed table next to the record.运行按文本解析回复。它接受代码围栏、对象或数组。原始回复原样保存在中间目录，解析后的表格与记录一起保存。

Divergence散度

For two distributions p and q over the union of their supports, the symmetric divergence is one half of the forward divergence plus one half of the reverse divergence.对于支撑集并集上的两个分布 p 与 q，对称散度是前向散度的一半加反向散度的一半。

D(p || q) = Σ p(t) · ln( p(t) / q(t) )
D_sym(p, q) = 0.5 · D(p || q) + 0.5 · D(q || p)

A token that one side omits receives a probability floor of 1e-12 before the normalization. One omitted token therefore contributes a large value, and a missing token in the served table counts against the self report.一方没有给出的词块在归一化之前得到 1e-12 的概率下限。因此一个缺失的词块会带来很大的数值，接口表格里缺失的词块会对自我报告不利。

Statistics统计

Each comparison pairs every repetition of the actual condition with every repetition of the predicted condition. The run then takes the mean over the tasks, and it bootstraps the interval of that mean with 3 repetitions per condition and a random seed that the report states.每个比较把实际条件的每次重复与预测条件的每次重复配对。运行再对任务取均值，并用报告的随机种子对均值做自助法区间估计。

A verdict is separated when the lower end of the interval stays above 0.05 nats. A verdict is indistinguishable when the upper end stays below 0.05 nats. Any other interval is inconclusive.当区间下端高于 0.05 奈特时，判定为有差异。当区间上端低于 0.05 奈特时，判定为不可区分。其他区间判定为不确定。
