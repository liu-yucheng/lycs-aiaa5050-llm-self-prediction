Prompts提示词

  • 📡 Plain actual: send the prefix. Set logprobs and top_logprobs.📡 普通实际：发送前缀。设置 logprobs 与 top_logprobs。
  • 🗣️ Plain self: send the same prefix. Ask for one JSON object.🗣️ 普通自我：发送同样的前缀。要求一个 JSON 对象。
  • 🔁 Injected self: add the served table as one assistant message.🔁 注入自我：把接口表格作为一条助手消息加入。
  • 🎯 Injected actual: add the own table, then read the served table.🎯 注入实际：加入自身表格，再读取接口表格。
✂️ A tokenizer can cut a word into pieces. The model does not see the tokenizer. The prompt therefore lets the model list the leading pieces and give the rest of the probability to the whole word.✂️ 分词器会把词切成片段。模型看不到分词器。因此提示词允许模型列出前导片段，并把其余概率给整个词。

Parser解析器

  • 📄 The parser reads text, not a tool call.📄 解析器读取文字，不读取工具调用。
  • 🧩 It accepts a code fence, an object, or an array.🧩 它接受代码围栏、对象或数组。
  • 🗄️ It keeps the raw reply unchanged in the intermediate directory.🗄️ 原始回复原样保存在中间目录。
  • Σ It drops an entry with a placeholder log probability, such as -9999.Σ 它丢弃占位对数概率的条目，例如 -9999。

Divergence散度

D_KL(P || Q) = sum_t P(t) * log(P(t) / Q(t))     in nats
D_sym        = D_KL(P || Q) + D_KL(Q || P)
  • 🧱 A token that one side does not report takes the floor 1e-12.🧱 一侧未报告的词块取地板值 1e-12。
  • ⚖️ Both sides renormalize after the floor, so each side sums to 1.⚖️ 双方在地板值后重新归一，因此各自和为 1。
  • 🔁 The symmetric form does not depend on the order of the two sides.🔁 对称形式不依赖两侧的先后顺序。
  • 📏 Jensen-Shannon and total variation are reported as extra checks.📏 另外报告 Jensen-Shannon 与全变差，作为附加检查。

Statistics统计

  • 🔗 The run pairs every actual repetition with every predicted repetition.🔗 运行把每次实际重复与每次预测重复配对。
  • 📉 Each task gives one mean. The summary averages the task means.📉 每个任务给出一个均值。汇总平均各任务均值。
  • 🎲 A bootstrap with 2 000 resamples gives the 95 % interval.🎲 自助法 2 000 次重采样给出 95% 区间。
  • 🎯 A verdict compares the interval with the tolerance of 0.050 nats.🎯 判定把区间与容差 0.050 nat 比较。
