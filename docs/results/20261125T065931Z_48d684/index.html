A language model writes one token at each step, and that step rests on a probability distribution over the next token. The model can show that distribution when the interface returns log probabilities. This experiment asks a different question: can the same model state that distribution as text, with no log-probability interface at all?语言模型每一步写一个词块，这一步由下一个词块的概率分布决定。接口返回对数概率时，模型可以展示这个分布。本实验问另一个问题：同一个模型能不能不用对数概率接口，只用文字把这个分布说出来？

Null hypothesis: a model reports its own distribution with no error, so the divergence is near 0 nats. Alternative hypothesis: a model does not learn to report its own distribution in training, so the divergence is larger than 0 nats.零假设：模型能无误差地报告自己的分布，因此散度接近 0 奈特。对立假设：模型在训练中没有学会报告自己的分布，因此散度大于 0 奈特。

The four conditions四个条件

The run applies four conditions to each task. Two conditions ask for a table. Two conditions put a table into the context and then measure again.本运行对每个任务使用四个条件。两个条件要求模型写出表格。两个条件把表格放进上下文，然后再测一次。

1 · plain_actual

The model reads the task and predicts the next token. The run reads the served table. This condition gives the ground truth.模型读任务并预测下一个词块。运行读取接口返回的表格。本条件给出基准真值。

2 · plain_self

The model reads the same task and writes the table of its own distribution as text.模型读同一个任务，用文字写出自己分布的表格。

3 · injected_self

The model reads the served table, and then writes its own table. This condition tests whether the model can read and rewrite a table.模型先读接口返回的表格，再写自己的表格。本条件检验模型能否读懂并重写表格。

4 · injected_actual

The model writes its own table, and then predicts the next token with that table in the context. This condition tests whether a self-prediction moves the real prediction.模型先写出自己的表格，然后在该表格位于上下文时预测下一个词块。本条件检验自我预测是否会改变真实预测。
