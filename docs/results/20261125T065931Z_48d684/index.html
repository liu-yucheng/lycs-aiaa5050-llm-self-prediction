The question问题

  • A model writes one token at each step. That step rests on a distribution over the next token.模型每步写一个词块。这个步骤依赖下一个词块上的分布。
  • The interface can show that distribution as log probabilities.接口可以把该分布显示为对数概率。
  • This run asks one question: can the model also state that distribution as text?本运行只问一个问题：模型能否用文字也说出这个分布？
🔍 The run compares two reports of one distribution. One report comes from the interface. The other report comes from the model itself.🔍 运行比较同一个分布的两次报告。一次来自接口，一次来自模型自己。

Two hypotheses两个假设

0️⃣Null hypothesis原假设Self-prediction is emergent. The divergence stays near 0 nats.自我预测是涌现的。散度接近 0 nat。
🔺Alternative hypothesis备择假设Training never rewards a self-report. The divergence stays above 0 nats.训练从不奖励自我报告。散度高于 0 nat。

Four conditions四种条件

1️⃣📡Plain actual普通实际Read the served table. This table is the ground truth.读取接口表格。该表格是基准。
2️⃣🗣️Plain self普通自我Ask the model to write its own table as text.要求模型用文字写出自己的表格。
3️⃣🔁Injected self注入自我Put the served table in context. Ask for the own table again.把接口表格放入上下文。再次索取自身表格。
4️⃣🎯Injected actual注入实际Put the own table in context. Read the served table again.把自身表格放入上下文。再次读取接口表格。
