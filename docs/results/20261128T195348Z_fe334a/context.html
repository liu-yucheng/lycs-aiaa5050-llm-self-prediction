The bootstrap problem自举问题

A model learns one operation: guess the next token. The operation is simple. The result is strong. A model writes code, retrieves knowledge, and deduces logic better than an average person can. Many of those abilities come from one educated guess of the next token.模型只学一个操作：猜下一个词块。操作简单，结果强大。模型写代码、检索知识、做逻辑推理，强于普通人。这些能力很多来自对下一个词块的一次有根据的猜测。

  • 🪞 If a model predicts its own guess, it holds a usable model of its own step. The step becomes observable from the inside.🪞 如果模型能预测自己的猜测，它就带有自己步骤的可用的模型。该步骤可从内部观察。
  • 📡 This run supplies the ground truth: the provider serves the top next-token table as log probabilities.📡 本运行提供基准：提供方以对数概率给出靠前的下一个词块表格。
  • 🗣️ The run then asks the model to state the same table as text, and compares the two tables.🗣️ 随后运行要求模型用文字说出同一表格，并比较两张表格。
