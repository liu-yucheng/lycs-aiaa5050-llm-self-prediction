Motivation动机

  • 🧱 Next-token prediction is the fundamental behavior of a large language model.🧱 下一个词块预测是大语言模型的基本行为。
  • 💪 The design works. A model writes code, recalls knowledge, and reasons through logic better than an average person can.💪 这种设计有效。模型写代码、回忆知识、做逻辑推理，强于普通人。
  • ✨ Many of those abilities emerge from an educated guess of the next token.✨ 这些能力很多来自对下一个词块的有根据的猜测。
  • 🪞 That raises the bootstrap question: can a model predict its own next-token prediction?🪞 于是出现自举问题：模型能否预测自己的下一个词块预测？
  • 🧠 A self-prediction task is one operational test of self-observation, and one narrow test of consciousness.🧠 自我预测任务是对自我观察的一次可操作检验，也是对意识的一次狭窄检验。

Two hypotheses两个假设

The null hypothesis is an optimistic assumption. It fits the expectation of the general public, which now treats a model as a human-like character. The assumption says that self-prediction has emerged. A self-report matches the served table, so the divergence stays near 0 nats.原假设是一个乐观假设。它符合公众的期待：公众已把模型当作类人角色。该假设认为自我预测已经涌现。自我报告与接口表格一致，因此散度接近 0 nat。

0️⃣Null hypothesis原假设Self-prediction is emergent. The divergence stays near 0 nats.自我预测是涌现的。散度接近 0 nat。
🔺Alternative hypothesis备择假设Training never rewards a self-report. The divergence stays above 0 nats.训练从不奖励自我报告。散度高于 0 nat。

The alternative hypothesis is a pessimistic assumption. It is ruthless, rational, and logical. No training objective rewards a self-report. So a self-report cannot match the served table, and the divergence stays significantly above 0 nats.备择假设是一个悲观假设。它冷酷、理性、合乎逻辑。没有任何训练目标奖励自我报告。因此自我报告无法与接口表格一致，散度显著高于 0 nat。

1️⃣📡Actual实际Read the served table. This table is the ground truth.读取接口表格。该表格是基准。
