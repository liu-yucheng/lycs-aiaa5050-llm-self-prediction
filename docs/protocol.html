Protocol of one run

The exact request bodies, the prompt rules, the injections, and the reply parsing rules.

The actual request

The plugin sends one system message and one user message, with temperature: 0, max_tokens: 1, logprobs: true, and top_logprobs: 20. The provider returns the top 20 entries of the first generated token. An endpoint that denies a field changes the body. The OpenAI provider omits the temperature, names the budget with max_completion_tokens, raises the budget to 16 tokens, and lowers top_logprobs to 5 when the endpoint denies 20.

POST <base_url>/chat/completions
{
  "model": "<model>",
  "messages": [{"role": "system", "content": "..."}, {"role": "user", "content": "..."}],
  "temperature": 0,
  "max_tokens": 1,
  "logprobs": true,
  "top_logprobs": 20,
  "stream": false
}

The self request

The self request asks the model to write the table itself. The request sets max_tokens: 2048 and no logprobs field. The reply must hold one JSON object with an entry list, where each entry gives a token and a log probability.

{"entries":[{"token":"霜","logProbability":-0.42},
            {"token":"光","logProbability":-1.05}]}

The prompt describes the tokenize cut. A tokenizer can split one word into several tokens. The prompt asks the model to list the leading pieces as separate entries and to give the rest of the mass to the whole word.

The two injected conditions

Actual then self. The plugin sends the task prompt, then one assistant message that holds the served table of the same repetition, then one user message that asks for the own table. The second table is the measurement.

Actual then actual. The plugin sends the task prompt, then one assistant message that holds the served table of the same repetition, then the task prompt again. The served table of the second read is the measurement. The first read of the pair is the actual table of the same repetition, so the folder needs no extra call.

The condition that reads the table twice is the control. It shows how far one reading stands from another reading of the same model and the same prefix. A divergence that stays near that level is not evidence of a self report.

The plugin writes a marker file for the reused first read, so a reader can tell a reused table from a fresh call. The marker holds no table.

The reply rules

Token namesApply NFKC and trim the token. Drop an empty token.
DuplicatesAdd the probabilities of two entries that name the same token.
Missing entryUse the probability floor of 1e-12 and renormalize the table.
Slow replyAdd one warning when a call takes more than 10 seconds.

The provider switches

  • thinking: disabled sends {"thinking": {"type": "disabled"}}, which the DeepSeek endpoint reads.
  • reasoning: disabled sends {"reasoning": {"enabled": false}}, which the Hugging Face router reads.
  • A model that reports one entry only is left out, and the run records one warning.
