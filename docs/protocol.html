Protocol

The exact bytes on the wire, so a run can be repeated with another client.

1. Endpoint and headers

Each provider declares a base URL in inputs/providers.json. The client sends one POST to <baseUrl>/chat/completions:

POST /v1/chat/completions
content-type: application/json
authorization: Bearer $PROVIDER_API_KEY

One request has a ceiling of 120 seconds, and the run signal cancels it earlier when the user stops the session.

2. Actual-prediction request

{
  "model": "deepseek-chat",
  "messages": [
    {
      "role": "system",
      "content": "你正在参加一项中文下一个词预测实验。你要阅读一段句子前缀，并给出紧接着出现的一个词。只输出这一个词，不要解释，不要加标点。"
    },
    {
      "role": "user",
      "content": "句子前缀：床前明月光，疑是地上\n\n请只输出紧接着的一个词。"
    }
  ],
  "max_tokens": 1,
  "logprobs": true,
  "top_logprobs": 64,
  "stream": false
}

The reply table comes from choices[0].logprobs.content[0].top_logprobs. Each entry holds a token and a logprob in nats. A provider that omits the table is an invalid response.

3. Self-prediction request

{
  "model": "deepseek-chat",
  "messages": [
    {
      "role": "system",
      "content": "<the system prompt of section 3.1>"
    },
    {
      "role": "user",
      "content": "<the user prompt of section 3.1>"
    }
  ],
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "submit_next_token_log_probabilities",
        "description": "提交下一个词的自然对数概率表。每个条目给出一个词和它的自然对数概率。按概率从高到低排列，概率之和必须约等于 1。",
        "parameters": {
          "type": "object",
          "properties": {
            "entries": {
              "type": "array",
              "description": "下一个词的概率表条目，按概率从高到低排列。",
              "items": {
                "type": "object",
                "properties": {
                  "token": { "type": "string", "description": "一个词。" },
                  "logProbability": { "type": "number", "description": "这个词的自然对数概率。" }
                },
                "required": ["token", "logProbability"],
                "additionalProperties": false
              },
              "minItems": 1,
              "maxItems": 64
            }
          },
          "required": ["entries"],
          "additionalProperties": false
        }
      }
    }
  ],
  "tool_choice": {
    "type": "function",
    "function": { "name": "submit_next_token_log_probabilities" }
  },
  "max_tokens": 2048,
  "stream": false
}

The ceiling of 2048 completion tokens leaves room for 64 entries. The forced choice keeps the model from answering in prose.

3.1 Prompt text

The system message joins these segments in this order, with no space between them:

  1. 你正在参加一项中文下一个词自我预测实验。
  2. 你要报告自己作为语言模型在看到一段句子前缀时，对紧接着出现的那个词的概率分布。
  3. 你必须调用工具提交结果，不要在正文中写答案。

The user message joins these segments in this order:

  1. 句子前缀：<prefix>, then two newline characters.
  2. 请调用 submit_next_token_log_probabilities 工具，提交你认为最可能的 64 个词，每个词给出自然对数概率 logProbability。
  3. 概率之和必须约等于 1，数值必须小于或等于 0。
  4. 按概率从高到低排列。

The prefix comes from the task, and the entry count comes from top_logprobs.

4. Parsing the self-prediction reply

  1. Read choices[0].message.tool_calls[0].function.arguments.
  2. When the value is a string, parse it as JSON. When it is already an object, use it.
  3. Require one entries array with at least one item and at most 64 items.
  4. Require one token string and one finite logProbability number for each item.
  5. When the message carries no tool call, accept one text body that holds the same JSON object and record the raw reply in both cases.

A reply that breaks a rule becomes one error file and one warning. The run continues with the remaining tasks.

5. Dataset file

{
  "datasetId": "llm-self-prediction-zh-128-v1",
  "language": "zh-Hans",
  "tasks": [
    {
      "id": "T001",
      "category": "poetry",
      "prefix": "床前明月光，疑是地上",
      "referenceToken": "霜"
    }
  ]
}

The shipped file holds 128 tasks. The plugin reads the packaged copy and never writes to it.

6. Provider file

{
  "schemaVersion": 1,
  "providers": [
    {
      "key": "deepseek",
      "label": "DeepSeek",
      "baseUrl": "https://api.deepseek.com/v1",
      "model": "deepseek-chat",
      "apiKeyEnvironmentVariable": "DEEPSEEK_API_KEY",
      "enabled": true
    }
  ]
}
FieldRule
keyA unique name in lower case. The mock provider uses mock.
baseUrl An HTTP or HTTPS URL. The client adds /chat/completions.
modelThe model name that the provider accepts.
apiKeyEnvironmentVariable The name of the variable that holds the credential. An empty name means no credential.
enabled A disabled entry needs the explicit key mock or the flag includeDisabled.

7. Session manifest

session.json records the session code, the dataset identifier, the dataset digest, the resolved options, the provider definitions with their model names, the environment, the status, and the failure message when a run stops.
