The hypothesis test

The bootstrap interval states the uncertainty of the mean. The hypothesis test states the evidence against the null hypothesis. The plugin runs one one-sided Wilcoxon signed-rank test for each comparison. The sample is the per-task median symmetric KL, the null value is the tolerance of 0.05 nats, and the alternative states that the median stands above the null value.

The test uses the normal approximation with a tie correction, and it drops every zero difference. A comparison rejects the null hypothesis when its p-value is below alpha, which is 0.05 by default.

The session holds the alternative hypothesis only when every comparison rejects the null and every median stands above the tolerance. The session holds the null hypothesis when no comparison rejects the null. A mixed result means that one comparison rejects and another one does not.

The alignment

Two tables rarely share one token set. The plugin builds the union of both token sets. A token that one table omits receives the probability floor of 1e-12, and each side is renormalized after the floor. The floor keeps the divergence finite and gives one missing token a large but bounded cost.

The alignment reports the union size and the coverage of each side, so a reader can tell a real disagreement from a narrow table.

The verdict

The plugin computes the mean symmetric divergence of each task, then one bootstrap interval of that mean with 2000 resamples and a fixed seed. The interval states how much the task sample supports.

Interval against the toleranceVerdict
The upper bound is below the tolerance.indistinguishable
The lower bound is above the tolerance.separated
The interval covers the tolerance.inconclusive
The comparison holds no pair.inconclusive

The default tolerance is 0.05 nats. One nat is a factor of e in probability, so the tolerance asks whether the two tables differ by more than about five percent in the exponential sense.

The warning about repetition noise

A self report varies across repetitions, and a served table can also vary at temperature zero. The interval covers the task sample, not the provider noise. A reader must compare the interval with the spread of the repetitions before the reader calls a small divergence a real one.
