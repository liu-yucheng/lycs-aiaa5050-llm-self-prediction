Does a model know its own next token?

A DeepSeek Harness plugin that measures how far the next-token table of a language model stands from the table that the same model reports about itself.

The question. A model reads a sentence prefix. The provider reports the top 20 next-token choices. Does the model know that table? The plugin asks the model to write the table, compares the two tables, and repeats the comparison under two injections.

Dataset
32 Simplified Chinese and 32 US English tasks in 8 categories in inputs/testing-dataset/
Providers
Hugging Face router models, plus a deterministic mock provider
Conditions
plain actual, plain self, injected self, injected actual; 3 repetitions each
Comparisons
3: plain self, injected self, and injected actual against the plain actual table
Verdict
Bootstrap interval of the mean symmetric KL against a tolerance of 0.05 nats

Why four conditions

  • The plain actual table is the ground truth, because the provider computes it and the model does not write it.
  • The plain self table shows what the model says when it must state its own prediction.
  • The injected self table shows whether the true table moves the self report toward the truth.
  • The injected actual table shows whether the self report distorts the served table that follows it.

What one run writes

  • outputs/<xid>/intermediate/ holds every raw exchange, one file for each call.
  • outputs/<xid>/results/ holds the metrics, the records, the report, and the tables.
  • outputs/<xid>/demos/ holds the static bilingual demonstration website.
  • node lib/cli.js demos [<xid>] writes that website again from the current templates.

Install and first run

# register the package directory as a bundle
plugin_manager install_bundle target=<absolute path of this package>

# a dry run needs no credential and no network
node lib/cli.js run --dry-run --tasks=Z001,E001 --repetitions=1

# a real run reads the key from .env
node lib/cli.js env
node lib/cli.js run
