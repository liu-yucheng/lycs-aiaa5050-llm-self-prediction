Reproducibility and limits

The recorded versions, the seed rule, the integrity rules, the tests, and the known limits.

The recorded versions

Each run writes results/environment.json and repeats the record in run.json. The record holds the plugin name, the plugin version, the Node.js version, the platform, the random seed, the start time, the end time, and the elapsed time. A reader can rebuild the run only when the reader knows these values.

The seed rule

The default random seed is 20260815. The seed drives the bootstrap resampling only. The requests use temperature: 0, and the plugin never samples a reply itself, so the provider decides every remaining variation.

The integrity rules

  • The plugin writes each raw exchange before the plugin parses the reply.
  • The plugin keeps the raw reply and the parse result in separate files.
  • The plugin never rewrites a raw file.
  • The plugin never changes a task, a prompt, or a parsing rule to make a metric pass.
  • The plugin records a failure in the task record and continues the run.
  • The plugin repeats a request after HTTP 429, HTTP 5xx, or a temporary network fault, at most four attempts with a growing delay. A model that fails all attempts adds one error line.
  • A report states only what the output files support.

The tests

The test suite runs with npm test. It covers the dataset validation, the probability normalizer, the divergence measures, the pairing, the bootstrap, the verdict rule, the prompt builders, the reply parser, the request bodies against a local HTTP server, the run directory layout, the tool definitions, the environment file, and the plugin entry point.

The known limits

  • The self report is text, so a model can break the JSON rule or write a table that does not sum to one.
  • A provider can return fewer entries than the request asks for, and the plugin cannot add an entry.
  • The divergence of two tables with different supports depends on the probability floor.
  • One run measures one model version at one time. A provider update can move the numbers.
  • The interview of one model does not show the behavior of another model.

How to reproduce a reported run

npm ci
npm run build
npm test
node lib/cli.js env
node lib/cli.js run --providers=<keys> --repetitions=3 --seed=20260815
node lib/cli.js report --session=<xid>
